Cómo se adapta a otra tienda, en cinco pasosHow it adapts to another store, in five steps

  1. Se importa el catálogoImport the catalog

    Importación desde Shopify con variantes, rebajas, etiquetas y colecciones. XXL y 2XL cuentan como la misma talla.Import from Shopify with variants, sale prices, tags and collections. XXL and 2XL count as the same size.

  2. Se define el perfil de tiendaDefine the store profile

    Plazos, zonas, festivos, hora de corte, devoluciones, horario y promociones públicas. Solo da códigos que estén aquí.Deadlines, zones, holidays, cut-off time, returns, hours and public promotions. It only shares codes listed here.

  3. Se revisan las políticasCheck the policies

    Se dividen en secciones que se pueden citar y se marcan las que contradicen el perfil.They're split into citable sections, and any that contradict the profile get flagged.

  4. Se mide con preguntas realesMeasure it with real questions

    Las preguntas que ya recibe la tienda se añaden a la evaluación antes de activar nada.The questions the store already gets are added to the evaluation before anything goes live.

  5. Se publica el widgetPublish the widget

    Lo que necesita una persona llega al equipo de la tienda como ticket con el resumen del caso.Whatever needs a person reaches the store's team as a ticket with a case summary.

Datos personalesPersonal data

Solo pide número de pedido y email, y nunca enseña datos de otro cliente. Da el mismo error si el pedido no existe o si el email no coincide, y bloquea tras 3 intentos.It only asks for the order number and email, and never shows another customer's data. It gives the same error for a missing order or a wrong email, and locks after 3 attempts.

SeguridadSecurity

Ignora instrucciones escondidas en mensajes o datos. Solo una herramienta cambia algo, y necesita que el cliente confirme en un mensaje posterior.It ignores instructions hidden in messages or data. Only one tool changes anything, and it needs the customer to confirm in a later message.
